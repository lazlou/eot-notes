# Notebooks Overview
- [eot_parquet_access.ipynb](eot_parquet_access.ipynb): Notebook showing how to access the Parquet data for the End of Term (EOT) Web Archive hosted on AWS S3. A more detailed description of these steps and overview of the dataset is available here: [EOT Web Archive - Parquet Access Notes](../eot_parquet_access.md).
- [how_to_query_eot_data.ipynb](how_to_query_eot_data.ipynb): Notebook providing an initial overview of how to view and query the Parquet data with DuckDB.
