# Notebooks Overview
- [eot_parquet_access.ipynb](eot_parquet_access.ipynb): Notebook showing how to access the Parquet data for the End of Term (EOT) Archive hosted on AWS S3. A more detailed description of these steps and overview of the dataset is available here: [EOT Data Access](../how_to_access_eot_data.md).
- [how_to_query_eot_data.ipynb](how_to_query_eot_data.ipynb): This notebook gives an initial overview showing how to view and query the Parquet data with DuckDB.
